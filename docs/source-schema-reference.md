# NH General Court Source Schema Reference

This document tracks the original NH General Court SQL schema structure,
field naming conventions, and normalization mappings used by NH Deserves Better.

---

# committees

Original table:
committees

## Source Columns

```python
[
  'CommitteeCode',
  'LongName',
  'committeename',
  'committeeabbreviation',
  'committeelocation',
  'CommitteePhone',
  'oldCommitteeSecretary',
  'ActiveCommittee',
  'CommitteeResearcher',
  'CommitteeSecretary',
  'CommitteeAideEmailAddress',
  'CommitteeEmailAddress',
  'CommitteeID',
  'Database'
]
```

## Normalized Columns

| Source | Normalized |
|---|---|
| CommitteeCode | committeecode |
| LongName | longname |
| CommitteePhone | committeephone |
| ActiveCommittee | activecommittee |
| Database | database_name |

## Notes

- `CommitteeID` is the primary join field for testimony.
- `Database` renamed to `database_name` to avoid reserved-word ambiguity.
- Boolean fields normalized during sync.

# docket

Original table:
docket

## Source Columns

```python
[
  'SessionYear',
  'LSR',
  'ExpandedBillNo',
  'StatusDate',
  'CondensedBillNo',
  'LegislativeBody',
  'Description',
  'DataBase',
  'legislationid',
  'OrderDate',
  'statusorder'
]
```

## Important Fields

| Column | Purpose |
|---|---|
| legislationid | Primary bill join key |
| CondensedBillNo | Human-facing bill number |
| ExpandedBillNo | Full bill number version |
| StatusDate | Latest legislative status date |
| LegislativeBody | House/Senate |

## Notes

- `legislationid` is the critical relational key across most tables.
- `CondensedBillNo` is used for exports and bill lookups.

# legislators

Original table:
legislators

## Source Columns

```python
[
  'PersonID',
  'LastName',
  'FirstName',
  'Employeeno',
  'MiddleName',
  'LegislativeBody',
  'Active',
  'seatno',
  'countycode',
  'District',
  'party',
  'Expr1',
  'Address',
  'address2',
  'city',
  'Zipcode',
  'Expr2',
  'EMailAddress',
  'GenderCode',
  'SecretaryID',
  'database'
]
```

## Important Fields

| Column | Purpose |
|---|---|
| PersonID | Legislator identity key |
| Employeeno | Used in roll call joins |
| District | Legislative district |
| LegislativeBody | House/Senate |

## Notes

- `Employeeno` joins to `rollcallhistory.EmployeeNumber`.
- `PersonID` joins to sponsors.
- Some fields like `Expr1` and `Expr2` appear autogenerated/unclear.

# sponsors

## Important Join

```txt
sponsors.PersonID
→ legislators.PersonID
```

## Notes

- `PrimeSponsor` normalized to boolean.
- Sponsor withdrawals tracked separately.

---

# rollcallsummary

## Purpose

Stores vote-level metadata.

One row per roll call event.

## Important Fields

| Column | Purpose |
|---|---|
| VoteSequenceNumber | Vote event identifier |
| CondensedBillNo | Bill reference |
| Yeas/Nays | Vote totals |

## Notes

- Does NOT contain `ExpandedBillNo`.
- Joins to `rollcallhistory` using:
  - SessionYear
  - LegislativeBody
  - VoteSequenceNumber

---

# rollcallhistory

## Purpose

Stores individual legislator votes.

One row per legislator vote.

## Important Join

```txt
rollcallhistory.EmployeeNumber
→ legislators.Employeeno
```

## Notes

- Used for accountability scoring.
- Used for legislator vote histories.

---

# houseRemoteTestify

## Purpose

Stores submitted remote testimony.

## Important Join

```txt
houseRemoteTestify.legislationID
→ docket.legislationid
```

## Notes

- `nonGermane` normalized to boolean.
- No sessionyear field directly exists.
- SessionYear inferred through docket join.
